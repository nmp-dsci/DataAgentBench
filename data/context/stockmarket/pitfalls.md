- `stockmarket_stocktrade_all._table` is lowercase (e.g. `aaau`) per samples, while `stockmarket_stockinfo.Symbol` is uppercase (e.g. `AAAU`) — a join between them needs `lower()`/case-fold; no measured overlap for this pair exists in joins.md, so exact match behavior is unverified.
- `stockmarket_stocktrade_all."Date"`, and `Date` in every per-ticker table, is `character varying`, not a date type — sorting/comparison as text will work for the `YYYY-MM-DD` samples shown but is not guaranteed for all rows since column is text.
- `stockmarket_stocktrade_all."Date"` vs `stockmarket_cmi."Date"` only reach 0.9528 raw overlap (10,887→11,196 comparison) — some dates in one side are missing from the other; joining on Date alone can silently drop rows for certain tickers.
- `stockmarket_cvx."Date"` vs `stockmarket_cmi."Date"` overlap only 0.8105 — different tickers have different date coverage (different listing/trading histories), so a join across two individual ticker tables on Date will not return all rows for both.
- `stockmarket_stockinfo."Financial Status"` is null for 74.2% of rows (2,043/2,752) — per hints.txt, null does not appear in the defined code list (D/E/Q/N/G/H/J/K), so its meaning (e.g. unknown vs. not applicable) is not stated in the material; treat null as distinct from `N` (Normal).
- `stockmarket_stockinfo."Market Category"` value `Not applicable or not NASDAQ-listed` (2,042/2,752 rows) is a literal string, not a null — must be matched exactly if filtering on category.
- `stockmarket_stockinfo."Round Lot Size"` has only one distinct value (100.0) across all 2,752 rows — carries no discriminating information.
- `stockmarket_stockinfo."Test Issue"` has only one distinct value (`N`) across all 2,752 rows — carries no discriminating information.
- `stockmarket_stockinfo."NextShares"` is `N` for 2,751 of 2,752 rows and `Y` for exactly 1 — extremely skewed, easy to miscount as "no variation."
- `stockmarket_stockinfo."Nasdaq Traded"` is `Y` for all 2,752 rows despite the name implying a filterable flag — per description.txt it means "Whether stock is traded on NASDAQ," but every row present in this table is `Y`, so filtering on it changes nothing within this table.
- Per-ticker trade tables (e.g. `stockmarket_cvx`, `stockmarket_cmi`) carry no ticker/symbol column — the ticker is only encoded in the table name itself, or in `_table` for the union view `stockmarket_stocktrade_all`.
- Two distinct table families exist for per-ticker trade tables: 2,715 tables (incl. `stockmarket_cvx`) with `Volume` as `bigint`, and 38 tables (incl. `stockmarket_cmi`) with `Volume` as `double precision` — type differs by family, relevant if unioning outside the provided `stockmarket_stocktrade_all` view.
- `stockmarket_cmi."Open"`, `High`, `Low`, `Close`, `Adj Close`, `Volume` each have null_rate 0.0001 (a small number of null rows) despite the schema listing them as populated fields; `stockmarket_cvx` has null_rate 0.0 on the same columns.
- Early rows in `stockmarket_cmi` (sample) and `stockmarket_cvx` (sample) show `Open = 0.0` while `High`/`Low`/`Close` are nonzero (e.g. cmi 1973-02-21: Open 0.0, High 5.5625) — `Open` of 0.0 does not necessarily mean a real zero opening price; treat as a possible data artifact for early dates.
- `stockmarket_stocktrade_all."Adj Close"` overlap with `stockmarket_cvx."Adj Close"` and `stockmarket_cmi."Adj Close"` is near-zero (0.0001–0.0037) — `Adj Close` values are not usable as join/match keys, unlike `Date`.
- `stockmarket_stocktrade_all` row count (6,236,194) and `_table` distinct count (1,292, noted "sampled": true in profile.json) do not match the "2,715 tables" count stated in schema.md — the profile's distinct count for `_table` is a sampled estimate, not exact.
- `stockmarket_stockinfo."Company Description"` mixes company/fund name and descriptive text in one field (per description.txt: "Company name and description") — there is no separate "name" column, so extracting a clean name requires parsing this free-text field.
- description.txt states stocktrade_database "contains daily price data for 2,753 individual stocks and ETFs," but schema.md counts 2,715 + 38 = 2,753 per-ticker tables total (two families) — matches, but note the two families have different `Volume` types as listed above.
