- `Patient_description` is free text from ~8 templates; every row has exactly one barcode `TCGA-[A-Z0-9]{2}-[A-Z0-9]{4}`, one disease/cohort name, one sex token `MALE`/`FEMALE` (use word-boundary match, since "FEMALE" contains "MALE"). Extract the disease name via several patterns (after "case of"/"subject with"/"diagnosed with"/"study of" up to a comma/period; "belongs to the ... cohort."; "In the ... dataset,") and coalesce them; don't assume one wording. Parse barcode/disease/sex first, then compare those parsed values exactly rather than `LIKE '%...%'` on the raw sentence.
- Cohort names in the text are full disease names (e.g. Breast invasive carcinoma), not acronyms like BRCA/LGG.
- "Histology type" usually means the coded field `icd_o_3_histology`, not the free-text `histological_type` — they disagree (one code maps to several text labels and vice versa). Missing values in many coded columns appear as bracketed sentinels; exclude with a regex like `!~ '^\[.*\]$'`, not just NULL checks.
- Join parsed barcodes to `ParticipantBarcode` exactly. "Reliable" mutations mean `FILTER = 'PASS'`; dedupe patients before counting presence.
- Postgres `log(x)` is already base 10; don't divide by log(10) again.
- For chi-square: build the full grid of every category x outcome pair (including zero-count cells) before totals, and apply a marginal-total cutoff to both row and column margins.
