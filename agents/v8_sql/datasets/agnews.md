- No category column exists. World/Sports/Business/Science/Technology must be inferred from `agnews_articles.title` + `description`. `doc` is only a JSON copy of those fields. The data is the standard AG News corpus (127,600 rows), which is balanced: about a quarter of the articles per category. A classifier whose shares for a year or region are far from 25% is miscalibrated.
- Joins are 1:1 on `article_id` and `author_id`. `agnews_authors.name` is unique, so filter on the exact name.
- `publication_date` is text 'YYYY-MM-DD', so string ranges work. Every region spans 2004-01-01 to 2022-12-30. `region` has 5 continent values, each with about 25.3k–25.7k rows. Totals are nearly equal, so a region ranking depends only on the classification. Return all regions with their counts.
- Keyword scoring that needs a strict winner leaves many articles unclassified. An ordered CASE works better: strong Sports signals first, then Business, then Sci/Tech, and everything else falls to World (politics, conflict, diplomacy, disasters).
- Source tags are strong signals. They sit at the end of a title in parentheses, or near the start of a description as '(Source)'. Sports: 'Sports Network', "Team Report" titles. Sci/Tech: PC World, SPACE.com, Ziff Davis, InfoWorld, MacCentral, NewsFactor, TechWeb, SiliconValley.com, COMPUTERWORLD, IDG NEWS SERVICE. Business: CBS.MW, Dow Jones, Forbes.com, Investor's Business Daily, TheDeal.com, Motley Fool, FT.com, 'Quote, Chart'. AP/Reuters/AFP appear in every category.
- Text artifacts: '#39;' is an apostrophe, a backslash is a line break, '\$' and '#36;' are a dollar sign, and HTML tags occur. Normalize before matching.
- For a small set (one author's articles), SELECT every row and judge each one by meaning. Tech products, software, the internet, space and science go to Sci/Tech. Stocks, earnings, mergers, oil and the economy go to Business.
