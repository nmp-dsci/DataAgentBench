- `patents_publicationinfo."Patents_info"` is one sentence per row from many templates. Extract fields with anchored regex, never `LIKE`/`split_part` on literal words:
  - **Country code**: 2-letter prefix of the publication number inside the sentence, e.g. `(?:publication|pub\.) (?:number|no\.) ([A-Z]{2})-...`. Don't match `LIKE '%DE%'`/`'%from DE%'` — those letters appear inside unrelated IDs/words too.
  - **Assignee**: two shapes — `"<NAME> holds the <CC> (patent )?(application|filing) ("` (assignee = text before it), or `... (owned by|assigned to|held by|belonging to) <NAME> (and has|, with) (publication|pub\.) (number|no\.) ...` (assignee = captured group). Assignee can be literal `[]` (none) — filter out. Compare assignees with exact equality only: "UNIV CALIFORNIA" is a prefix of "UNIV CALIFORNIA AT SAN DIEGO" and unrelated to "CALIFORNIA INST OF TECHN" — never substring-match.
  - **Publication number**: trailing ID before the final period, format `<CC>-<digits>-<kind>`; capture anchored at sentence end, not split on '.'.
- `cpc`/`citation` are JSON arrays as text; cast to jsonb, use `jsonb_array_elements`. `cpc` elements have `code`,`first`(bool=primary). `citation` elements have `publication_number` — join exactly to the target's extracted publication number, never `LIKE`.
- CPC subclass = first 4 chars of `code` (matches `patents_cpc_definition.symbol`, `level=5`); class = first 3 chars (`level=4`).
- date fields mix full/abbreviated month names, ordinal days, one 4-digit year, or `'None Date'`. Get year via `substring(col from '\d{4}')`; match months with a regex covering both forms.
- EMA of yearly counts per group: zero-fill the group's min-max year range via `generate_series`, seed at first year's count, recurse `ema(t)=0.1*n(t)+0.9*ema(t-1)`; don't use raw counts as EMA. Pick best year per group independently (max EMA, earliest year on ties), not the globally-highest value.
- CSV-quote a returned text field if it may contain a comma/quote.
