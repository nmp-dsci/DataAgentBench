09 · what this suggests next · nothing run without a go

Measure what the flagged rules are worth before building on them

  1. A clean champion. v6_sql with the 10 flagged units removed (a hand-built version, one run of the 54, ≈ $6). If Pass@1 holds near 0.89, the rules were not needed; if it falls, that fall is how much of the score rests on text §2.2 could flag.
  2. Audit inherited text every round. --strict reviews new writes only; running G1 over the units a version inherits (as section 04 did) would stop a round from carrying forward what it could not write today.
  3. Gains from tools, not more prompt text. With the reviewer on, the errors left mostly teach one question's reading. I2 (a code-built profile of each text column) and I1 (a check_sql verify step) teach the agent to find those readings in the data, which the rubric allows.
  4. Calibrate G1. One judge, one prompt: spot-check its 15 in-round and 10 audit verdicts before treating it as the rubric.
